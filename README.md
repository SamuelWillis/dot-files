# Dot Files

Settings and dot files I use for development.

## Editor

Right now I use [helix](https://helix-editor.com/). It's vim-like with a bunch of great improvements.

Very easy to set up and get running.

### Language servers

Helix requires you install language servers.

[Expert](https://expert-lsp.org/docs/installation/) - Installed via mise

## Dev envs

I use [mise](https://github.com/jdx/mise). It's very nice and easy to use.

It can install language servers for helix too, which is a bonus.


## Terminal

[Ghostty](https://ghostty.org/) with [zellij](https://zellij.dev/).

[Starship](https://starship.rs/) for a nice prompt.
